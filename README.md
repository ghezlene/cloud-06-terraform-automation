# Terraform Infrastructure as Code Lab

> Define infrastructure in code and make cloud environments repeatable.

## Overview

Infrastructure as Code allows infrastructure to be described, versioned, reviewed, and managed through configuration files.

This project explores Terraform and its role in automating infrastructure provisioning.

The objective is to move from manually creating infrastructure to defining it in a reproducible and maintainable way.

## Learning Objectives

- Understand Infrastructure as Code.
- Explore Terraform architecture.
- Understand providers and resources.
- Work with variables and outputs.
- Use Terraform initialization and validation.
- Understand plan, apply, and destroy.
- Explore Terraform state.
- Create reusable modules.
- Organize multiple environments.
- Understand resource dependencies.
- Apply safe infrastructure change practices.
